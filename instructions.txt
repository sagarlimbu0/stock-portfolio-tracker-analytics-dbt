# Setup dbt project
1. Create a environment
    python -m venv .env_dbt

2. Activate the environment
    source .env_dbt/Scripts/activate

3. Install required packages
    pip install -r requirements.txt

4. Initialize a dbt project
    a. dbt init <project-name>
    b. select the database
    c. Add the account identifier. full ACCOUNT identifier. EG: 'LDDEMIG-HJ34452'
    d. authentication type username & password or external browser by default

5. Add snowflake credentials on profiles.yml
6. Test the connection
    dbt debug
